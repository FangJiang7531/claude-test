# 海图古今 · AIGC 驱动的国风漫画交互叙事

从郑和下西洋到双十一航空物流：**一套调度系统，为什么在最拥挤的时候还能运转？**

## 运行

```bash
npm install
npm start            # http://localhost:5173
```

| 环境变量 | 作用 |
|---|---|
| `ANTHROPIC_API_KEY` | 接入 Claude 做 AIGC（也支持 `ant auth login` 的登录配置） |
| `CLAUDE_MODEL` | 默认 `claude-opus-5-5` |
| `AIGC_OFFLINE=1` | 强制离线：画面与文本全部由本地程序化生成，适合无网答辩现场 |
| `PORT` | 端口，默认 5173 |

没有凭据或调用失败时，前端会自动回退到本地生成，整套体验不会中断。

## 四个章节

| 章节 | 内容 | 交互 |
|---|---|---|
| 序章·海图开启 | 国风全景航海图，古代航路 / 现代航路切换 | 拖动平移、滚轮缩放，点击节点弹出 **景（分镜）· 数（数据）· 批（竖排批注）** |
| 第一章·郑和船队 | 宝船编队、官厂囤货、牵星过洋、古里互市 | 选航段、货物、天气、航法、是否经满剌加官厂 → 生成一回漫画并推演数据 |
| 第二章·双十一订单 | 重庆出发：下单 → 仓储 → 分拣 → 干线 → 枢纽 → 末端 | 设定策略后下单，**拖动锦囊**逐站前进；每站生成分镜、对白和数据 |
| 终章·古今对照 | 航线 / 枢纽 / 时效 / 风险 / 全球化 五维对照 | AIGC 结局与对联，生成可下载的「古今航迹对比海报」 |

## AIGC 三层

1. **分镜画面**：本地程序化水墨生成器（`public/js/ink.js`）会立即出图。勾选侧栏「AI 精绘分镜」后，再由 Claude 按提示词绘制 SVG 替换，单张约 1–1.5 分钟。每格都可以展开查看「画面提示词」。
2. **叙事文本**：回目、旁白、对白、批注由 Claude 以结构化 JSON 生成（`/api/story`），也支持输入关键词即兴成回，如「从泉州到古里」「双十一爆仓」。
3. **用户行为影响结果**：`public/js/sim.js` 中的模型。
   - 船队：航期、货损、补给压力和结局随天气、航法、货物与官厂选择变化。
   - 订单：用排队论（M/M/1 近似）计算各节点负荷。前置仓、加节点、分拣速度、洪峰倍数和运输方式共同决定总时效、成本、碳排放、爆仓风险，以及「准时达 / 略有延误 / 爆仓延误」三种结局。多次下单会列表对比。

  map.js    序章海图        geo.js  手绘海岸线与投影

## 数据说明

史实数据（首航约 62 艘宝船、27,800 余人、满剌加官厂出自马欢《瀛涯胜览》等）与现代物流数据均取自公开资料的常见口径，界面中标注为「约」。第二章的时效、成本、碳排为**教学用简化模型**，不是真实运营数据。参赛或答辩前，建议逐条核对出处。
